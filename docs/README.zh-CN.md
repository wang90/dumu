# Dumu 文档（Web 官网）

[English Docs](README.md)

这个目录用于放置面向 Web 官网的文档内容（可作为官方文档/官网介绍页来源）。

## 目标

- 提供给用户看的产品文档
- 复用为官网首页和文档页内容
- 与项目根目录的开发说明分离

## 建议的网站内容结构

- `Overview`：dumu 是什么、解决什么问题
- `Features`：核心能力和截图
- `Quick Start`：安装、启动、首次保存
- `Chrome Extension`：扩展安装与快速保存流程
- `FAQ`：常见问题和排查
- `Privacy`：离线数据与隐私说明

## 内容编写建议

- 面向用户，内容简洁、可执行
- 官网默认英文展示
- 中文作为独立语言入口维护
- 优先步骤化说明，减少长段落

## 发布方式

- GitHub Pages（静态文档）
- VitePress / Docusaurus（需要版本化文档时）
- 任意静态托管平台（Netlify、Vercel、Cloudflare Pages）
