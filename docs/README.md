# Dumu Docs (Web Website)

[中文文档](README.zh-CN.md)

This folder contains documentation content intended for a public web website (official docs/homepage usage).

## Purpose

- Provide product-level documentation for users
- Reuse content for an official website landing page
- Keep docs separate from development notes in the project root

## Suggested Website Structure

- `Overview`: What dumu is and why it exists
- `Features`: Key capabilities and screenshots
- `Quick Start`: Install, run, and first credential save
- `Chrome Extension`: Setup and quick-save flow
- `FAQ`: Common issues and troubleshooting
- `Privacy`: Offline-first data handling statement

## Content Guidelines

- Keep user-facing content concise and practical
- Default to English for public pages
- Provide Chinese as a translated entry when needed
- Prefer task-oriented steps over long paragraphs

## Publishing Options

- GitHub Pages (static markdown site)
- VitePress / Docusaurus (if you need versioned docs)
- Any static hosting platform (Netlify, Vercel, Cloudflare Pages)

## Next Step

If you want, we can add a ready-to-run docs site template next (for example VitePress), so this folder can be deployed as an official website directly.
